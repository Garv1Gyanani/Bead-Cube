# Bead-Cube

A calm 3D spatial puzzle game built with Flutter (`flutter_scene`) where colorful polyomino bead blocks fold seamlessly across 90° cube edges.

## Repository Structure

- **`beadcube/`** — Flutter mobile game (`com.beadcube.game`) for Android & iOS featuring 100 progressive levels, Daily Cube mode, 5 serene visual themes, and offline progress persistence.
- **`beadcube-web/`** — Clean, minimal React + Vite static landing page and store-compliant Privacy Policy (`/privacy-policy`), pre-configured for Netlify.
